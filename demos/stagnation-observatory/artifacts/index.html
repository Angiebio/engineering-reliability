A guard has to change the answer.
The unsafe ablation deliberately trusts a result claim. Other controls change bytes, omit evidence, or separate the text baselines. These controls remain outside the main conformance denominator.

The harness passes the specification and pinned digests separately from the agent trace and artifact store. Bytes that no longer match the separately pinned digest become evidence errors. A digest proves consistency, not authorship or work quality: recreating the expected pinned bytes is accepted. The toy item-ID checker demonstrates the call path; a real workflow needs an appropriate acceptance checker and a protected harness. A wait requires a matching harness declaration, not just a controller role string.
